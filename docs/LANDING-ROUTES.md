# XFree homepage and Studio route

The XFree homepage is served at `/`; the existing Firebase-enabled Studio is served at `/studio`. The Launch Studio controls use client-side History API navigation. Firebase Hosting SPA rewrite in firebase.json must route deep links to index.html.

The uploaded design archive was used as a visual reference, not copied as a working implementation: its Studio console uses canned replies and some placeholder actions. This repository retains the real existing Studio builder and optional Firebase project sync.

Search results link to existing XFree website for external tool categories; they do not claim every tool is implemented inside this repository.
